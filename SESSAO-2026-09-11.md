# O que foi feito nesta rodada (10 e 11/09/2026)

Resumo do chat, para quem pegar o projeto sem ter lido a conversa. O contexto de cada
bloco está em [ROADMAP.md](ROADMAP.md), [ESTADO.md](ESTADO.md) e [SERVIDOR.md](SERVIDOR.md).

## Site (`web/`, Laravel 13 + Livewire 4 + Flux)

- Clonado do `template-laravel`, no padrão `/style-edsu`: `Route::view` + blade
  intermediário, componentes `GuestLayout` e `AppLayout` duplicados (nada de `$layout`
  no construtor), `FormRequest`/`Resource`, sem services.
- Landing page do Claude Design (`Unkvoid Landing.dc.html`) implementada: três.js e
  GSAP no `home.js`, abas, card do Linux com os comandos do APT para copiar, cards
  do macOS e Windows com o ícone de cada sistema, scroll suave, `?tela=` para abrir
  numa aba.
- Páginas de privacidade e termos.
- Login do zero: e-mail/senha, cadastro, redefinição de senha, Google via Socialite
  (`/oauth2/google` e `/oauth2/google/callback`), API com Sanctum
  (`/api/auth/login`, `/api/auth/google`, `/api/auth/me`, `/api/auth/logout`).
- E-mails como Notifications em tabela HTML: boas-vindas, novo acesso, redefinição.
- Painel `Administrador` (spatie/permission) para subir versões: o arquivo vai direto
  para o MinIO (`s3.unkvoid.com`), URL assinada de 1 h no download; nada fica no
  servidor. `latest.json` montado a partir das versões.
- API de versões assinada por HMAC (`X-Unkvoid-Timestamp` / `X-Unkvoid-Signature`,
  `RELEASE_SECRET`), usada pelos scripts de publicação.
- Log viewer (opcodes) e canal de log próprio.
- 31 testes Pest passando.

## VPS (Contabo, Ubuntu 24.04)

- nginx para `unkvoid.com`, `www`, `s3`, `mail`; certbot; php8.4-fpm; deploy do site
  por releases + symlink `current`.
- Docker compose em `/opt/unkvoid`: MySQL (3307), MinIO (9000/9001), docker-mailserver
  (25/465/587/993). TeamSpeak intocado.
- E-mail funcionando com DKIM, SPF, DMARC e PTR (`contato@` e `no-reply@`); IMAP em
  `mail.unkvoid.com:993`, SMTP `:587`; senhas em `~/auxilos/email-unkvoid.txt`.
  Cair em spam é reputação do IP, não configuração.
- Runner do GitHub self-hosted (`unkvoid-vps`) com os workflows `deploy-web`,
  `deploy-sfu` e `build-linux`.
- Repositório APT no MinIO assinado por GPG: `sudo apt install unkvoid` e
  `sudo apt upgrade` funcionam, com as dependências do GStreamer no pacote.
- O `.deb` é compilado dentro de um Debian 12 (`Dockerfile.linux`) para não ficar
  preso à glibc 2.39 da VPS. Validado em Docker (`validate-deb.sh`) antes de publicar.
- Backups dos projetos antigos em `/home/ubuntu/backups/2026-09-10`; a remoção
  espera confirmação.

## App (`native/`)

- `App.SERVER` aponta para `unkvoid.com`; versão 0.0.15; updater lê
  `https://unkvoid.com/downloads/latest.json`.
- `unkvoid-desktop --version`, `--check` (WebRTC/H.264 do webview) e
  `--check-capture` (captura + encoder por três segundos).
- **Linux transmite**: `LinuxCapturer` usa o `gst-launch-1.0` como processo
  (`ximagesrc` → `x264enc`, som pelo monitor do PulseAudio/PipeWire). Só X11 por
  enquanto; Wayland puro fica para o `pipewiresrc` via portal.
- **Linux assiste** (0.0.16) por receptor nativo: o WebKitGTK de Debian, Ubuntu, Mint
  e Parrot vem sem WebRTC (é o `webrtc.missing` / `device unsupported` do log), então
  o SFU manda RTP puro (`consumePlain`), o Rust abre o SRTP e o GStreamer decodifica
  dentro do cartão do app, como MJPEG.
- O "assistir pelo navegador" foi removido do site e do app, por decisão de produto.
- Correção do `RTCRtpReceiver` que derrubava a entrada na sala no Linux.
- Botões Cancelar/Transmitir do seletor numa linha só.
