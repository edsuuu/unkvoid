# O que é o Unkvoid

O Unkvoid é um aplicativo de desktop para grupos que precisam conversar e compartilhar a tela. O espaço de cada grupo é um **servidor**: nele ficam os membros, os cargos, os canais e o histórico de chat.

Cada pessoa entra com a própria conta. Não há sala avulsa criada por código: voz, chat e transmissão pertencem a um canal de um servidor.

## O que um servidor reúne

- **Canais de texto** para conversar e enviar imagens.
- **Canais de voz** para falar, usar a transmissão de tela e trocar mensagens no chat do próprio canal.
- **Categorias** para agrupar canais de texto e voz.
- **Cargos e permissões** para definir quem vê, conversa, entra em voz ou administra cada parte do servidor.
- **Convites** para trazer pessoas para o grupo sem abrir o servidor para todo mundo.

O servidor começa com o cargo `@everyone`, um canal de texto chamado `#geral` e um canal de voz chamado `Geral`. A pessoa que o cria é a dona dele.

## O que o Unkvoid não promete

[Clips](/documentacao/guia/clips) é um replay local exclusivo do Windows e não faz parte de servidores, chat ou voz. A câmera funciona nos clientes macOS e Linux; o cliente Windows ainda a mantém desativada.
