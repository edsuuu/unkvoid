# Primeiros passos

Você precisa de uma conta para participar de um servidor e entrar em voz. Depois de entrar no aplicativo, o caminho básico é este.

1. Crie um servidor com um nome para o seu grupo, ou entre em um usando um convite recebido.
2. No servidor novo, use `#geral` para mensagens e `Geral` para voz.
3. Crie cargos e canais quando o grupo precisar de uma organização diferente.
4. Gere um convite se você tiver a permissão `CREATE_INVITE` e envie-o para quem deve entrar.

## Entrar por convite

O convite adiciona a conta ao servidor. Se a pessoa já é membro, aceitar o mesmo convite não cria uma segunda entrada nem repete a mensagem de chegada. Uma conta banida não consegue entrar pelo convite.

## Comece simples

Para um grupo pequeno, o cargo `@everyone` já permite ver canais, escrever, entrar em voz, falar, transmitir tela e criar convites. A permissão `VIDEO` também vem nesse cargo: ela libera câmera nos clientes macOS e Linux, enquanto o cliente Windows ainda a mantém desativada. Em um servidor maior, retire ou conceda permissões por cargo e por canal antes de distribuir o convite.

Veja [Como usar um servidor](/documentacao/guia/usar-um-servidor) para a organização e a moderação.
